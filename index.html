🔌 Skema & Integrasi ESP32

  1. 6× DS18B20 satu bus OneWire di GPIO4 (DQ gabung, pull-up 4.7kΩ ke 3V3, power eksternal 3V3, bukan parasite).
  2. GPIO D23 → SSR IN → Solenoid Valve (AC 220V via steker, sudah disediakan mitra).
  3. Flash firmware/smart-cow-sprinkler-firebase.ino dari Arduino IDE, isi WiFi + URL DB + Database Secret di bagian atas file.
  4. ESP32 kirim telemetri tiap 2 dtk ke devices/cow-sprinkler-01/telemetry/latest, baca perintah dari .../control.
  5. Buka web yang sudah deploy, datanya mengalir otomatis. Perintah dari web (mode, threshold, jadwal, manual) dibaca ESP32 tiap 5 dtk.
Detail lengkap + wiring ada di README.md. Web butuh ESP32 online untuk menampilkan data.
